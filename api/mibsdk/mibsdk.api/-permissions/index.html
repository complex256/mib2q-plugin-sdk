Permissions

class Permissions(source)

Permission ids a plugin declares in plugin.json. The build refuses a call whose permission is not declared, and the runtime refuses it when the owner has not granted it: a permission must be both declared and granted, and a plugin that misses one is not enabled at all (BLOCKED_PERMISSIONS). Revoking any single permission stops the whole plugin. The owner sees the approval text from api/permissions.json.
