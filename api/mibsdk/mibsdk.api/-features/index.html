Features

class Features(source)

Features the running firmware adapter may support. Read them with has, at call time: the adapter can learn a feature after this plugin was enabled, and a feature it lacks this boot may be there after a restart. Never assume one; a missing feature makes the matching Ui call inert, not failing.
