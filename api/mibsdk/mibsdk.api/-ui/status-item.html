statusItem

abstract fun statusItem(text: String): StatusItem(source)

One short status-line item; set(null|"") hides it. A plugin has at most MAX_STATUS_ITEMS live at once. Text longer than MAX_TEXT characters is truncated. Needs ui.slot.statusbar; inert without SLOT_STATUS_BAR.

The line is shared: the runtime's own indicators come first. The safety ones (SAFE, PDC R OFF) always show; the others give way to plugin items. The items share what is left fairly, so no plugin's item can crowd out another's. An item shorter than an equal share is shown whole; a longer one may be cut to its share (with ... when the share is wide enough), so put the most important text first. Items follow the user's order, then plugin id; when even three characters each do not fit, the last items in that order are left out (all of them if none fits). The user may hide this plugin's item or move it earlier or later from its page in the Plugins menu. None of that is visible to the plugin: set keeps working and never fails because the item is hidden or cut.

abstract fun statusItem(text: String, icon: Icon): StatusItem(source)

statusItem with an icon; a null icon means none. An installed icon larger than ICON_MAX_PX throws IllegalArgumentException. Without Features.UI_ICONS the item shows without it; the checks are the same either way.
