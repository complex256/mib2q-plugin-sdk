Ui

interface Ui(source)

Declarative plugin UI. Obtained from ui. Text is never rejected for length: the runtime truncates it. Exceeding a count limit throws IllegalStateException; a missing or invalid argument throws IllegalArgumentException.

A missing feature is not an error. When the unit lacks the feature (the SDK UI is off this boot, or the unit has no such slot) each method still returns a handle, but an inert one: update, open, set and cancel are accepted and show nothing. Count limits and argument checks apply as usual, so a plugin that works with the UI on works the same with it off. Use has to tell the two apart.
