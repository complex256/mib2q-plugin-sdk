PageSpec

class PageSpec(source)

The content of a plugin page. Immutable; every builder call returns a new PageSpec.

Ids (page and item) must match [A-Za-z0-9._-]{1,32} and item ids must be unique within a page, else IllegalArgumentException. Text is never rejected: the runtime truncates it to the MAX_* lengths. Adding entry MAX_ENTRIES + 1 throws IllegalStateException.

Input entries (api 5: choice, dropdown, slider, progress, an item with an icon, enabled) need "api": 5. Without UI_INPUTS the unit shows them as text lines ("Level: Mid", "Progress: 60%") and item icons only with UI_ICONS. Dropdown and slider rows are drawn after the list rows, in spec order. A slider shows its position, not its number. A slider's knob may lag a fast turn near its ends until the plugin's update arrives.
