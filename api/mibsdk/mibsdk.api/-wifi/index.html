Wifi

interface Wifi(source)

The unit's Wi-Fi client uplink. Obtain it from wifi; needs NETWORK_WIFI.

The car's own access point stays available while the client is connected: the stock Wi-Fi service runs the access point and the client together. This API only manages the client side (the internet uplink).

connect and disconnect ask the car to act; they return at once. Watch onChanged or poll status for the result. scan blocks until the car reports its results or the timeout expires.
