mibsdk/mibsdk.adapter.fake

Package-level declarations

A host-only fake car for plugin and runtime tests.

mibsdk.adapter.fake.FakePlatform implements the platform adapter in memory: ignition, parking-sound writes, hooks and features. mibsdk.adapter.fake.FakeUi renders the UI snapshot and drives it as a user would.

This package is host-only. It never ships to the unit.
