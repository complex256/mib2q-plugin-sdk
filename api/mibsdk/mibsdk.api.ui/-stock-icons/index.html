StockIcons

class StockIcons(source)

The names of the SDK's built-in icons, for stockIcon.

Built-in icons need no file and are always small enough for a Car row, a page item or a status item.

The second group is the car's own ring set: the glyphs of the 3D ring the main menu uses. They are drawn by a ring page; on a Car row, a list row or a status item they show without an icon (the ring glyphs live in the HMI's 3D atlas, not in a PNG). Use them for a ring page's items, and the shapes above elsewhere.
