# Internal documentation

This directory holds the engineering record behind the SDK. It is **not** user documentation and is
excluded from the published docs site.

| Directory | Contents |
|---|---|
| `research/` | Reverse-engineering notes: the onboard Java map, HMI UI injection, menu and icon research, native inputs, carplay-rgi compatibility |
| `superpowers/specs/` | The original design specification |
| `superpowers/plans/` | Implementation plans and task breakdowns |
| `bench-e2e*.md`, `bench-e2e/` | Bench end-to-end records and screenshots |
| `car-readiness.md`, `car-session-runbook.md` | Car readiness gates and the first-car-session runbook |
| `developer-bumps.md` | A historical audit of the SDK's rough edges, written while writing the first tutorial |

These files are kept for history. Paths, version numbers and behaviour in them may be out of date.
User-facing documentation lives one level up, in `docs/getting-started/`, `docs/guides/`,
`docs/reference/` and `docs/explanation/`.
